# Maintainers

SecureDynamics, Inc. maintains ZCC Log Explorer through the
`SecureDynamicsInc` GitHub organization.

## Current merge authority

- `@SecureDynamicsInc/zcc-maintainers` — designated maintainers and Code Owners
- SecureDynamics organization owners — administrative continuity and final
  governance authority

## Appointed maintainers

- Kevin Peterson (`@kpex-sd`)
- Conor Peterson (`@cpsd038`)

The live GitHub team membership and repository permission are authoritative if
this list ever falls out of date.

Additional SecureDynamics team members and community participants are valued
contributors. They receive maintainer or merge authority only when explicitly
appointed by an organization owner and reflected in repository access controls.

Maintainers are expected to:

- protect customer and diagnostic data;
- implement accepted Issues on local topic branches and require passing checks;
- obtain approval from the other appointed maintainer before integrating a
  change into `main`;
- apply the DCO and project license consistently;
- disclose conflicts of interest;
- follow `GOVERNANCE.md`, `SECURITY.md`, and `CODE_OF_CONDUCT.md`; and
- avoid using maintainer access to bypass normal review except for a documented
  emergency security response.

Independent Codex and Claude reviews are recommended when administratively
useful, but they are non-blocking and not required for integration.
