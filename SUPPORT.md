# Support

ZCC Log Explorer is a community-maintained SecureDynamics project. It is
provided as-is, without an uptime, response, remediation, compatibility, or
support service-level agreement.

## Where to ask

- Use a GitHub Issue for a reproducible bug, documentation problem, missing
  error code, or enhancement request. External pull requests are not accepted;
  SecureDynamics maintainers implement accepted requests independently.
- Use the repository's private vulnerability-reporting channel for security
  concerns.
- Customers with a separate SecureDynamics services agreement should use the
  support route in that agreement for contracted assistance.

Maintainers decide priorities based on safety, reproducibility, customer value,
project scope, and available capacity. Opening an Issue does not guarantee that
SecureDynamics will investigate, accept, or deliver a change.

## Protect customer data

Do not post raw support bundles, logs, packet captures, credentials, tenant
identifiers, user or device names, private addresses, or customer-specific
configuration. Reduce the problem to synthetic evidence. Maintainers may remove
unsafe content and close reports that cannot be handled safely in public.

For questions about Zscaler products or production incidents, use the official
Zscaler documentation and your authorized Zscaler support channel. Analyzer
findings are best-effort troubleshooting guidance, not an official support
determination.
