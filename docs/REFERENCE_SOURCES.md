# External reference sources

The analyzer includes a normalized local catalog so engineers can identify
known ZCC, ZIA, ZPA, and ZDX conditions without sending diagnostic data to an
external service. Each catalog family links to the corresponding complete
Zscaler Help reference for current context and updates.

| Catalog family | External reference |
| --- | --- |
| ZCC error codes | https://help.zscaler.com/zscaler-client-connector/zscaler-client-connector-errors |
| ZCC connection status | https://help.zscaler.com/zscaler-client-connector/zscaler-client-connector-connection-status-errors |
| ZPA session status | https://help.zscaler.com/zpa/understanding-zpa-session-status-codes |
| ZPA authentication | https://help.zscaler.com/zscaler-client-connector/zscaler-client-connector-zpa-authentication-errors |
| ZIA authentication | https://help.zscaler.com/zia/internet-saas-authentication-error-codes |
| ZIA Kerberos authentication | https://help.zscaler.com/zia/internet-saas-error-codes-kerberos-authentication |
| ZIA policy reasons | https://help.zscaler.com/zia/policy-reasons |
| ZDX web probe | https://help.zscaler.com/zdx/web-probe-errors |
| ZDX cloud path | https://help.zscaler.com/zdx/cloud-path-errors |
| ZDX managed probe | https://help.zscaler.com/zdx/zscaler-managed-probe-errors |
| ZDX remediation | https://help.zscaler.com/zdx/remediation-errors |

The local severity is a SecureDynamics triage hint, not an official Zscaler
support priority. Product behavior and documentation can change. When a catalog
entry is missing or differs from the current external reference, open a fully
redacted Issue with the code, product, and external source link. Never attach a
customer log or capture.
